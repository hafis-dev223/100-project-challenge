## Tentang Proyek

Repository ini berisi 100 proyek pengembangan web yang dibuat untuk meningkatkan kemampuan pemrograman, pemecahan masalah, UI/UX, dan pengembangan perangkat lunak.

Setiap proyek menghadirkan tantangan baru dengan tingkat kesulitan yang terus meningkat, dimulai dari website statis hingga aplikasi web dinamis dan pengembangan full-stack.

## Tujuan

- Memperkuat fundamental HTML, CSS, dan JavaScript.
- Meningkatkan logika pemrograman dan kemampuan memecahkan masalah.
- Membangun antarmuka yang responsif dan mudah digunakan.
- Mempelajari pengembangan frontend dan backend.
- Memahami database dan API.
- Mempelajari arsitektur perangkat lunak dan keamanan.
- Membangun proyek secara mandiri dari nol.
- dan untuk bisa ke web3 

## Teknologi

Teknologi akan dipelajari dan diterapkan secara bertahap sepanjang tantangan ini.

- HTML5
- CSS3
- JavaScript
- TypeScript
- React
- Node.js
- Database
- Teknologi lainnya sesuai kebutuhan proyek.
